    Phases

    Guiding decisions

    Engine first, two front ends

    One C++ engine with CUDA, Metal and CPU backends. The OFX plugin and the standalone workbench are both clients, plus a CLI and Python API for farm work.

    Workbench in its own process

    Host OFX panels can't hold a node graph or heat maps, and a second Qt UI inside Nuke risks clashes. The plugin launches the workbench and feeds it host frames, the pattern Mocha Pro uses.

    Dense direct solver at the core

    ESM on SL(3) with robust IRLS and a photometric model uses every weighted pixel, gives sub-pixel accuracy, down-weights occluders automatically, and makes the heat map nearly free. Feature matching is a support system for initialization and re-acquisition.

    Track in a perceptual space

    Scene-linear EXR highlights dominate a least-squares solve. Tracking input goes through OCIO into log (for example ACEScct) by default.

    Holdouts you can read

    Every track, shape, matte operation and export is a node. A holdout is a visible edge into a Subtract node, and "shape follows track" is a visible edge too. A layer list edits the same graph for quick setups.

    Why it slipped: the heat map

    Feasible, because the direct solver already computes a residual, weight and Jacobian per pixel. At the solution the update is a sum of per-pixel contributions, so each pixel's push on the track is known exactly.

    Δp = H⁻¹ · Σᵢ wᵢ Jᵢᵀ rᵢ     H = Σᵢ wᵢ Jᵢᵀ Jᵢ     cᵢ = H⁻¹ wᵢ Jᵢᵀ rᵢ
    • Contribution map: project each cᵢ onto the unexpected motion, a single DOF, or a clicked corner ("which pixels pushed this corner that way").
    • Weight and residual maps: what the robust estimator ignored, and where reference and frame disagree.
    • Coarse-level and accumulated modes for gross failures and slow drift.
    • Slip analyzer: ranks likely causes (occluder entering, lighting change, degenerate texture, motion blur, plane leaving frame, motion too large, reflection or parallax) with a one-click fix for each.

    Track savers artists rarely ask for

    • Stabilized view and reference flicker as the main QC tools; drift is obvious long before it shows on a grid.
    • Separate tracking region and insert surface: track the whole wall, pin the poster.
    • Global refinement pass over all frame homographies to remove slow drift on long shots.
    • Lens-distortion-aware tracking; a planar track through a distorted lens is wrong at the edges.
    • EXR data window, overscan and anamorphic pixel aspect handled in every export, the classic source of 1–2 px offsets.
    • Frame-number and timecode mapping between MOV (frame 0), EXR (1001) and host time.
    • Lighting curve export: the solver's gain/bias drives a Grade so the insert flickers with the plate.
    • Trackability preview and best start frame suggestion before you track.
    • Roto from tracks: the same shapes export as keyframed Nuke Roto or Flame GMask.
